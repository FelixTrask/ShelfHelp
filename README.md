# ShelfHelp

ShelfHelp is an iPhone app that turns an empty Little Free Pantry into an alert, so the neighbors and stewards nearby who want to help know it needs filling. The app shows a map of local pantries, each one marked green when it is full or red when it is empty, so you can see at a glance which boxes need attention. Anyone walking by can report a box as empty, which turns its pin red and sends an alert to the people signed up to keep it stocked. Once someone refills it, they can turn the pin back to green.

Tools used:
- Expo, Expo-router, and the create-expo app template
- React Native and react-native-maps
- Supabase
- Expo Push Service
- AsyncStorage
- The Haversine Distance Formula
